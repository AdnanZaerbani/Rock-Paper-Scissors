Rock Paper Scissors

A console-based Rock Paper Scissors game developed using C#.

Overview

A simple player-versus-computer game where the computer randomly selects Rock, Paper, or Scissors and the result is determined according to the game rules.

Features

- Player versus computer gameplay
- Random computer choices
- Win, loss, and draw detection
- Score tracking
- Input validation

Technologies

- C#
- .NET
- Console Application

Purpose

This project was developed to practice:

- C# fundamentals
- Conditional logic
- Random number generation
- Loops
- Input validation
- Problem solving
